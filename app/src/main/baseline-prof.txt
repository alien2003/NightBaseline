# The app is small, so every class and method of the app's own packages is compiled ahead of time: start-up, the
# Home / History / Settings screens, their scrolling (rows, press feedback, overscroll) and the glass shell.
# AndroidX and Compose bring their own profiles in their AARs (merged by AGP; R8 rewrites all rules for the release
# build). Libraries on the tab-switch and push / pop path whose AARs ship no or only a thin profile are listed below
# (checked in build/intermediates/merged_art_profile): navigation-compose and the navigation runtime, the lifecycle /
# ViewModel / Hilt Compose glue, saveable state, lazy lists and the animation library (crossfades, transitions).
# Haze ships a profile for its core and blur modules only; the whole library is listed because the glass shell
# draws with every scrolled frame (the top bar's progressive blur and Haze's trace helpers were not covered).
